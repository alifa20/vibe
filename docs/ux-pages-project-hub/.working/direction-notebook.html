entry no. 08

zcal

Single-user scheduling: read one calendar, publish availability, book a slot.

One person, one calendar, one SQLite file on your own disk. No accounts, no analytics.

what it does

  1. Reads one calendar: an .ics feed, an upload, or busy blocks you add by hand.
  2. Publishes your free time as bookable slots.
  3. A visitor reserves a slot. No account needed.
  4. Writes the event back to that calendar.

run it locally

in your terminal
cd zcal
npm run bootstrap  # deps, .env, sample data
npm run dev        # localhost:3000

It needs a server because bookings live in SQLite, which GitHub Pages can't run.
