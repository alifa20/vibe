direction 03 / sticker-sheet

a sheet of stickers,
one per thing

every project gets its own loud colour and becomes a chunky sticker: thick black outline, hard offset shadow, a little "inspired by" label slapped on the corner. it's the most playful of the four and the easiest to find things in, because you end up remembering "the blue one".

the maker log shows up as stuff stuck on stuff: a tilted "made with ai" pill, labels on screenshots, the colour following you onto each project page and into the nav strip's switcher.

zcal

Single-user scheduling: read one calendar, publish availability, book a slot.

inspired by Zcal needs a server next.js + sqlite
screenshot: booking page
screenshot: pick a time
screenshot: booked!

what it does

  • reads one calendar
  • publishes your free time
  • a visitor grabs a slot, no account
  • writes the event back

run it locally

~/vibe
$ cd zcal
$ npm run bootstrap  # deps + .env + sample data
$ npm run dev        # localhost:3000

Needs Node 20.9+. It can't live on GitHub Pages because your bookings sit in a SQLite file.
