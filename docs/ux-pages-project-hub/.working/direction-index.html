a swiss-style catalogue page. strict 12-column grid, one typeface, big light numerals doing the wayfinding. the numbers are the identity: "08" is zcal on the hub, on its page and in the nav strip, so you learn the set by number.

i

what it does

  1. aReads one calendar.
  2. bPublishes your availability.
  3. cA visitor reserves a slot.
  4. dWrites the event back.

ii

run it locally

cd zcal
npm run bootstrap   # installs, writes .env, adds sample data
npm run dev         # http://localhost:3000
needs Node 20.9 or newerdata: one SQLite fileno accounts, no telemetry
