keyboard order and targets

← vibe→‹→● switcher→›→app
  1. 0“skip to teleprompter”, before the strip, hidden until focused.
  2. 1← vibe back to the hub. pill, 44px tall.
  3. 2‹ “previous: zcal” (wraps around the manifest). 44×44.
  4. 3switcher <summary> “switch project, current: teleprompter”. enter/space opens it; tab walks the menu, footer last.
  5. 4› “next: personal-site”. 44×44.
  6. 5the app itself.

fit at 375: 8px padding, 6px gaps; ≈ 82 + 44 + 168 + 44 + gaps = ~366px. one line. a long current name truncates with an ellipsis inside the pill rather than wrapping the strip.

focus is a 3px dashed ink ring, 2px off, on the yellow; hover only nudges the shadow, so the two never look alike.
