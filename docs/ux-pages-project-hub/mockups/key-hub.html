hub: grouped vs single grid

the one open layout call. same eight cards, same copy, same hover and focus states; only the grouping changes. then both at 375 in dark, and the 404 that shares the hub chrome.

illustrates

  • DESIGNcomponents: project card, status badge, section heading, 404
  • DESIGNlayout & spacing (2/3-up vs 4-up), elevation (hover), shapes
  • EXPinformation architecture: hub layout is still open
  • EXPstates: hover / focus, missing path · voice
  • EXPresponsive < 600px · accessibility floor (focus, badge text)

Agrouped

  • says it up front: the first two run, the other six don't. the headings do the work.
  • live demos get 42px names and more room, which suits the only two you can click straight into.
  • costs one more heading to scroll past on a phone.

Bsingle grid

  • one scan, all eight, in manifest order; the badge alone carries live vs server.
  • fits above the fold at 1200. names drop to 28px so "personal-site" fits a quarter column.
  • on a phone it's almost identical to A, minus one heading.
