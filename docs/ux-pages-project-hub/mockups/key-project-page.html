zcal

single-user scheduling: read one calendar, publish your free time, someone books a slot.

inspired by Zcalneeds a servernext.js + sqlite

what it does

  • one calendarbusy blocks, .ics import and export
  • booking linkslength, buffers, notice, how far ahead
  • visitors see free times onlynever your event titles
  • booked = written backplus a .ics and a one-time cancel link

run it locally

zsh · ~/vibe
# from your clone of alifa20/vibe
$ cd zcal
# deps + .env + sample data
$ npm run bootstrap
# → http://localhost:3000
$ npm run dev

needs node 20.9+. bootstrap prints a passphrase: that's your login. it can't live on github pages because your bookings sit in a sqlite file.

golinks

link shortener with click analytics and qr codes, on your own domain.

inspired by Bitlyneeds a servercloudflare workers + kv + d1

what it does

  • 302 at the edgethe click is logged after the redirect
  • per-link analyticsclicks/day, countries, devices, referrers
  • a qr png per slug/qr/{slug}, cached at the edge
  • expiry and click capsthen it falls back to your site

run it locally

zsh · ~/vibe
# from your clone of alifa20/vibe
$ cd bitly
$ npm install
# set a local ADMIN_PASSWORD
$ cp .dev.vars.example .dev.vars
# once: local d1 tables
$ npm run db:init:local
# wrangler dev → 127.0.0.1:8787
$ npm run dev

runs on cloudflare workers, so it needs wrangler, not a box. local kv and d1 live in .wrangler/, apart from production. to ship it: npx wrangler login, then npm run deploy.
